# Code-for-Ridgeless-interpolation-under-spiked-model
This is a code repository for figures and tables in the paper ''High-dimensional ridgeless least squares interpolation under spiked covariance structures''.
In the paper, the asymptotic risk curves as a function of the aspect ratio $\gamma$ are output generated by ``risk_analysis_4line.m''; Asymptotic risk surfaces for the bias (blue) and variance (orange) terms as functions of $\gamma$ and the summation of spiked eigenvalues $\sum_{i=1}^{M}\alpha_i$ is output generated by ''risk_decomposition_3D2D.m''; The asymptotic risk surface varying with $\gamma$ and the summation of spiked eigenvalues $\sum_{i=1}^{M}\alpha_i$ is output generated by ''risk_3D2D.m''; The asymptotic risk surface varying with $\gamma$ and $\left\langle \boldsymbol{u_i},\boldsymbol\beta\right\rangle^2$ is output generated by ''risk_alignment_3D2D.m''; Tables and figures in real data analysis section are output generated by ''cifar10_Rempirical_picture.py'' and ''cifar10_checktest.py''.
